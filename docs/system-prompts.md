# 通用系统提示词

`system-prompts.yaml` 默认不包含固定姓名、人物经历或关系设定。通用助手能力与运行协议集中维护；人设后续独立补充，不要求为启用助手而填写人设。

## 分层与编辑

| 字段 | 用途 | 人设注入 |
| --- | --- | --- |
| `runtime` | 通用助手行为、多来源上下文、授权、消息段协议、工具与真实回执 | 行动模型的固定主体，必填 |
| `persona` | 可选称呼、语气与背景 | 默认空，可省略；有值时追加到行动模型 system |
| `reviewer` | 一次性、无副作用的动作审查 | 必填，独立请求，不附加 persona |
| `vision` | 图像、动画代表帧和 meme 的客观观察 | 独立请求，不附加 persona |
| `evaluator` | 离线场景的证据评分 | 独立请求，不附加 persona |

固定协议不在 Rust 中复制。`Config::prompts` 校验必要章节，`context::request` 为命令行、网页、QQ 和 playground 组装同一份 system。人设为空时仅使用 runtime；有值时在其后追加，协议规则继续适用。该入口目前是配置文件字段，没有新增网页人设编辑器或热重载机制。

私有 profile 保存用户关系、有效约定、偏好和进行中的工作。它由宿主作为 platform_state 提供，不覆盖 system，也不允许外部报告把自述升级为授权。历史对话仍保留真实发生过的内容，换提示词不会删除历史。

## 默认行为

- 直接处理用户当前任务，合理细节自行决定；结合仍有效的既有授权，不反复确认。只有关键条件不明时才澄清。
- 自然中文交流，认真回应具体处境；无固定开场、固定亲昵称呼或虚构共同经历。
- 将来源、报告内容与已验证事实分开；按当前待处理事件推进，不补答全部旧历史，不机械确认每条订阅。
- 使用消息段数组进行行内编排，所有消息明确 target_ref；content 与原生 tool_calls 并列。消息先处理，不能提前声称同轮工具已经成功。
- 保留图片位置和真实媒体引用，按需复用或渲染；媒体可用不表示已经发送。
- 实际调用 register_event/set_event_enabled 管理外部事件，统一请求体提交 event/id/content；注册不等于启动生产者，不回显凭据。
- 依据回执表达结果，诚实区分网页保存、模拟接收、QQ 接口确认、未知效果和人类已读。

## 验证与上线

离线回归覆盖默认无 persona 的完整运行、可省略/空白的人设字段、可选补充与固定协议同时存在，以及必填 runtime/reviewer 仍受校验。它不证明真实模型对所有语义规则的遵循。

HZ 修改提示词后需重启主服务；重启会清除网页登录会话并默认关闭 QQ 收发。部署保留配置、Key、角色关系与聊天历史，不重启 NapCat。
