# 模型配置与统一上报（2026-10-29）

WebUI 增加模型配置；外部报告改为模型实际调用工具注册，统一使用 `POST /sync/hooks/events`。运行说明与请求示例见 [HZ 试用服务](hz-trial.md)。

## 实现

- `src/web/models.rs` 管理私有模型设置与不可变配置快照。保存后，下一轮主模型与审查使用同一快照；视觉使用按模型、端点和选项区分的缓存。设置与宿主 profile 元数据在同一数据库事务中提交。
- 可编辑服务商链接、API基址、自定义对话端点、模型名、Key、超时、输出上限及请求选项。Key 不回显，修改服务地址需显式提供新的 Key。连接测试只发起一个小型请求，不保存设置，不进入助手对话。
- `src/reporting.rs` 提供注册表、独立事件凭据和原始入站。`register_event` 与 `set_event_enabled` 由原生工具调用发起，沿用同一个动作审查与执行器。注册不是执行外部工作，也不产生自动业务分支。
- 外部请求体包含 event、id、content，可选 occurred_at、correlation_id。来源类型从注册表读取，调用者不能自称主人；没有来源会话兜底。鉴权、启用状态检查和原始入账共用一个事务，原有去重实现由所有入口共享。
- 口令保存在私有注册表，只对已登录管理页提供。模型目录、工具回执与事实不含这些凭据；能力变化使旧审查失效。旧静态 hooks 地址移除，不自动迁移成未经模型登记的事件。
- 数据库升至版本4，保留旧事件与动作事实，新增私有设置和事件表。部署前已建立权限受限的数据库备份。

## 验证与限制

32 项离线回归通过，两个需真实模型/独立渲染器的用例默认忽略；Clippy、格式和网页脚本语法检查通过。新增检查覆盖：

- 模型配置保存、乐观版本冲突、私有持久化、Key 不回显及不进入事实、视觉配置缓存分离、协议选项保护、更换服务地址时阻止静默携带旧 Key。
- 注册、同名定义保护、停用与重新登记不自动启用；统一路径的来源绑定、请求去重、伪造身份拒绝和跨事件口令隔离。
- HZ 上线后，模型配置保存成功，数据库版本4、权限0600，统一端点及管理接口可用。保存后的 Key 与原环境一致。

真实连接测试中，当前 Command Code 凭据在 HZ 与用户此前指定的本机 dsh 文件中均得到服务商 HTTP 401。因此本轮没有声称通过真实模型注册/接收的完整链路；需要在新配置入口换入可用凭据后继续验证。连接测试会显示服务商状态，失败不会保存测试输入，也不会改写已经保存的设置。
